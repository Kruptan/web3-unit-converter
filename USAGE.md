# Usage

The converter supports two directions.

## Token to Raw

For an ERC-20 token with 18 decimals:

1. Enter `1`.
2. Set decimals to `18`.
3. Select `Token → Raw`.
4. Click Convert.

The result is:

`1000000000000000000`

## Raw to Token

Enter:

`1000000000000000000`

with:

`18`

decimals.

The result is:

`1`
